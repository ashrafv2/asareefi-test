مصاريفي 2.0 — الإصدار المعتمد للتجربة والنشر

1. احفظ نسخة JSON شاملة من تطبيقك الحالي على Google Drive أو iCloud Drive قبل أي تحديث.
2. ملفات النشر: index.html و manifest.webmanifest و sw.js و icon-192.png و icon-512.png.
3. عند فتح إصدار 2.0 لأول مرة على GitHub قد تكون بياناته فارغة لأن النسخة القديمة تستخدم مساحة تخزين مختلفة. استرجع نسخة JSON من شاشة «النسخ الاحتياطي» أو اختر استيراد بيانات الإصدار السابق إن كانت متاحة في نفس الموقع.
4. صور الفواتير وPDF محفوظة محليًا؛ استخدم التصدير الشامل الذي يتضمن المرفقات.
5. يفتح زر «إضافة دخل أو مصروف» لوحة الإدخال السريع.
6. التصنيفات والألوان من الإعدادات، الدخل المتكرر من سجل الدخل، والتحليل من التقارير.
7. يظل النشر على GitHub خطوة مستقلة عن تجهيز هذه الحزمة. لا تدّعِ نشرها قبل رفع الملفات.
8. نفّذ تجربة عملية كاملة على Safari وتحقق من استعادة البيانات قبل اعتماد الموقع.

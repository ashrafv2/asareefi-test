النسخ الاحتياطي

فحص سلامة البيانات

يفحص سجلات النسخ المحفوظة، بما فيها النسخ القديمة، واتساق الحسابات والمرفقات، وتجربة ترميز ملف فاتورة. لا يغيّر أي بيانات أو أرصدة.

لم يُشغّل الفحص بعد. احفظ نسخة احتياطية شاملة أولًا.

نجاح الفحص الأولي لا يغني عن اختبار تنزيل JSON الشامل ثم استعادته على جهاز أو متصفح منفصل.

استيراد سجلك المالي القديم

يمكنك استيراد ملف JSON المحوّل من تطبيق «مصاريف» القديم (سنوات 2013–2023) مع المصروفات والدخل والتصنيفات. يبدأ التطبيق الجديد دون بيانات تجريبية، ولا يستورد أي شيء تلقائيًا. الاستيراد يستبدل البيانات الحالية بعد التأكيد؛ احتفظ بنسخة احتياطية قبل استعادة أي ملف.

تصدير نسخة كاملة إلى السحابة يدويًا أو استرجاع نسخة محفوظة. ستتضمن النسخة الجديدة صور الفواتير وملفات PDF وتواريخ الضمان.

استرجاع النسخة يستبدل جميع البيانات الحالية بعد التأكيد. احفظ نسخة احتياطية قبل الاسترجاع.
